## 项目原始定位

从国内外不同平台的视频、文章、项目和讨论中，持续发现、学习和跟进新知识，形成便于回顾、比较和实际使用的汇总与总结。

## 项目范围

- **来源**：小红书、B 站、GitHub，以及海外的视频平台、博客、社区、官方文档等。平台范围保持开放，按具体学习主题选择。
- **主题**：Skill、插件、模型、AI 工具、开发方法、教程和其他有价值的新知识，不局限于工具发布资讯。
- **内容形式**：视频、文章、代码仓库、发布说明、文档和社区讨论。
- **目标**：理解新内容讲了什么、有什么价值、如何使用、与已有知识有什么联系，以及后续发生了什么变化。

## 初始工作方式

以下作为起步方案，随实际使用调整。

1. **收集**：接收用户分享的链接或素材，也可根据指定主题主动检索。记录标题、平台、作者、原始链接、发布日期和收集日期；缺失的信息留空。
2. **阅读与提取**：从可获取的正文、视频字幕、演示和代码中提取要点，说明实际阅读或观看的范围。获取不到的部分保留为待补充。
3. **理解与核实**：整理核心概念、使用方法、适用场景和重要条件。涉及具体能力、版本或用法时，按需要对照官方文档、原始仓库或论文。
4. **整合**：将不同来源对同一主题的内容合并，保留各自提供的新信息；比较相似工具和不同观点，连接到已有知识。
5. **学习与实践**：把需要动手的内容拆成小练习或验证任务，分别记录已阅读、已理解、已实践和待验证的情况。
6. **汇总与跟进**：产出单条笔记、专题总结和阶段汇总；跟进版本变化、后续实践结果，以及需要修正的旧结论。

## 单条学习笔记的参考结构

- **基本信息**：标题、主题、平台、作者、链接、发布与收集日期。
- **内容覆盖**：实际读到的文章、字幕、视频片段、文档或代码范围。
- **一句话概括**：这条内容最值得记住的是什么。
- **关键知识**：主要观点、方法、步骤和必要示例。
- **使用价值**：适合解决什么问题，与当前学习或工作有什么联系。
- **核实与实践**：来源中的说法、查证结果、自己的判断和实际操作结果。
- **后续行动**：值得继续阅读、尝试或跟进的事项。
- **更新时间**：涉及模型、插件或软件时，同时记录相关版本信息。

结构按内容复杂度裁剪，简单素材可以只写短笔记。
