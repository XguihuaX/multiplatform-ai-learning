## 这套方法能帮你做什么

它把“让AI生成一段日常动画”拆成可修改的小产物：小剧本、分镜表、角色与场景参考、首帧、对白、逐镜候选视频、最终剪辑。适合先制作一个4–6秒双人反应镜头，再扩展成多镜头短片。这里的新价值是明确每一步应该确定什么，出错时知道回哪一步修改；不是发布了一种新的基础视频模型。

相比只给一段长提示词，首帧承担角色外观、服装、站位、道具和画风，动态提示词主要说明接下来怎么动。这样可以在生成视频前先看见并修正开场构图。它不能保证整个片段的人物一致性，仍需实际审片。

## 七步流程与每步产物

1. **小情节**：确定人物A想做什么、人物B怎样回应，先写动作和必要对白。例如A展示自己做的饼干，B看一眼后微笑。产物是一小段可以读出时长的剧本。
2. **分镜**：逐镜记录景别、人物位置、动作、对白、结束姿势，以及观众到这一刻知道了什么。写明为什么切镜、下一镜接的是视线还是反应。产物是有镜号的表格。
3. **首帧与参考**：使用对应服装的人物参考和共同场景，先确定能交代空间的主镜，再由此设计近景和反打。人物图负责“是谁”，场景图负责“在哪里”，首帧负责“开始时是什么状态”。
4. **对白节奏**：先录试音确认语速、停顿和反应时间。支持音频参考的生成工具可输入试音，其他工具可在剪辑中同步。不要把十秒对白硬塞进四秒动作。
5. **逐镜生成**：一镜优先只安排一个主动作。首帧确定起点，动态提示词交代动作顺序、镜头是否移动和结束姿势。每次保留候选版本，避免覆盖唯一可比较的结果。
6. **审片返修**：开场外形或位置错误回首帧；动作走样先缩小动作范围；前后空间不连贯回分镜。检查手与物体接触、人物身份、口型和镜头首尾。
7. **剪辑导出**：先接顺动作、对白和停顿，再加字幕、环境声和音乐。最后播放完整导出文件检查接缝，不能仅看每段单独生成成功。

## 一个可以直接开始的小案例

下面是本库自拟练习，不是原视频逐字提示词。目标是做六秒无对白的双人反应镜头，先排除口型同步的复杂性。

| 项目 | 设计 |
| --- | --- |
| 开场 | 固定中景；A在画面左侧，双手托盘；B在右侧，视线朝向A |
| 主动作 | A把托盘轻轻举高，B先看托盘，再抬眼微笑 |
| 镜头 | 固定机位，保留两人头部、双手和托盘，不增加转场 |
| 结束 | 两人站位保持不变，B微笑短暂停留 |
| 参考 | 两名角色对应服装参考、一张室内场景参考、一张确认过的首帧 |

首帧提示词应把静态关系讲清，例如：“室内暖光，双人中景，左侧人物双手托着饼干盘，右侧人物看向左侧人物；清楚轮廓、简洁赛璐璐分色，光源来自画面左上，托盘与双手完整入镜。”实际角色外观应从自己的参考图补充。

动态提示词可以写：“固定镜头，左侧人物缓慢把托盘抬高少许，右侧人物视线落到饼干上，再抬眼看向左侧人物并微笑，末尾稍停；人物保持原站位。”不要同时要求转身、绕镜、走路、递盘、吃饼干，否则难以判断是哪一步造成失败。

第一遍审片只检查四件事：人物有没有换脸或服装漂移；托盘是否真的被双手托住；视线先后顺序是否正确；最后的停顿是否足够看清反应。若手指变形，先减少托盘移动幅度并检查首帧接触关系；若人物互动正确但显得急，优先调整动作时长或剪辑停顿。

## 为什么会有“日常番”的感觉

按官方流程的分析，关键不仅是线条风格，还包括注意力和节奏：先让观众理解人物与场景的位置，再给触发动作，最后留出反应。一个物件特写可以让观众知道发生了什么，随后切人物表情就有了理由。每镜都问“观众先看哪里”，可以帮助控制背景细节、颜色和景别。

色彩上先统一环境大色面和光源方向，再保留角色辨认色；不要让每个镜头各自生成完全不同的光线。镜头时间以动作和对白落点决定，并非全部使用相同长度。原项目流程中的地铁口、门铃案例解释了这种切镜方法；本次读取的是文字分析，未独立播放那些案例成片核对声音。

## 可迁移到自己的AI工作流

Skill可以承担拆镜、参考清单、首帧提示词和返修建议；图片生成、视频生成、配音与剪辑由实际工具完成。先保存一张分镜表即可，不必一开始搭复杂系统。建议字段为：镜号、输入参考、首帧路径、动作、对白时长、结束姿势、候选文件、采用原因与待修问题。

官方仓库还提供两期教程跟练资料入口，包含首帧、分镜和提示词等。此次没有下载完整跟练包，也没有验证其中所有资产。开始练习时可以用自己的角色素材代替，核心方法不依赖麦麦或糖糖这两个人物。
