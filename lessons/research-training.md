# 模型训练与科研：把新方法读成可以检验的实验

本章串联收藏中的微调、蒸馏、AI Infra、记忆检索和自动科研。学习目标是：看见“新训练方法”“效果提升”“自动发现规律”时，能解释方法改了什么，并设计最小对照实验。

## 1. 先把训练方法放到正确的坐标上

“LoRA、SFT、DPO、蒸馏”不是同一个维度的四选一。应分别问：训练哪些参数？使用什么数据？优化什么目标？

| 维度 | 要回答的问题 | 例子 |
| --- | --- | --- |
| 参数更新方式 | 全部权重还是一部分？ | 全参数微调、LoRA |
| 数据组织 | 用什么监督信号？ | 指令回答、成对偏好、教师生成答案 |
| 学习目标 | 让哪个量变好？ | 模仿参考答案、提高偏好回答的相对概率 |
| 压缩/迁移目的 | 希望把谁的能力迁给谁？ | 大教师模型产生数据，小学生模型学习 |

因此可以用 LoRA 做 SFT，也可以用教师生成的数据做 SFT 来完成一类蒸馏。仅列“十种微调方式”容易掩盖这些组合关系。理解维度以后，才能读懂项目配置。

## 2. 一个可理解的蒸馏实验

假设目标是让较小模型将客服问题分成退款、物流、产品咨询三类。先准备一批问题，用教师生成标签和解释；检查含糊样本，再用这批数据训练学生。另留一组从未参与生成、筛选或调参的测试问题。

完整流程应写为：任务定义 → 数据抽样 → 教师生成 → 质量筛选 → 学生训练 → 独立评估。教师可能出错，学生会学到这些错；长解释也未必比短解释更适合任务。

至少比较三种情况：原学生模型、只用人工样本训练的学生、加入教师数据的学生。固定测试集、指标和推理设置。若只展示几个挑选出的成功案例，很难知道提升是普遍发生还是抽样选择造成的。

用于分类的最小指标是准确率及各类错误分布；如果某类很少，整体准确率可能掩盖它的失败。进一步可记录推理时间、部署资源和每类召回率，判断换成学生是否值得。

## 3. 不要让宣传解释替代论文的实验结论

收藏 X06/X12 涉及 DeepSeek-R1、PRM和MCTS。阅读原论文时要区分论文最终采用的方法、讨论过的方法、尝试后没有采用的方法。R1论文第4.2节将相关PRM/MCTS尝试放在不成功尝试的讨论中。学习时应把“为什么没有奏效”保留下来，不能改写成模型成功的核心秘诀。

这提供了一个阅读模板：问题是什么 → 实际训练流程是什么 → 哪组实验证明了哪项收益 → 尝试失败的条件是什么。引用具体论文段落能帮助后续AI避免沿用二手误读。[原论文第4.2节](https://arxiv.org/html/2501.12948v1#S4.SS2)。

## 4. AI Infra：为什么有模型文件还不等于能运行

推理资源消耗至少包括权重、运行时工作区、KV cache 和服务并发。以7B参数、每参数2字节为粗略估计，权重本身约14GB十进制存储；这还没有加上缓存与工作区。量化能降低权重占用，但实际速度还取决于硬件和算子实现。

KV cache 保存自回归生成时已计算的注意力键和值，避免每生成一个新token就重新计算已有部分；上下文更长或同时服务更多请求时，缓存通常会增大。前缀缓存进一步复用多个请求共有前缀的计算。它们与“把用户偏好写入Markdown”属于不同层次。

服务体验也要拆开：TTFT看第一个文本token何时出来；后续token速度影响长回答生成；并发吞吐影响同时服务多人时的成本。吞吐高不必然意味着单用户等待最短。TTS里的首音与RTF区别，是同一种指标拆解思想。

一个可做的实验是保持模型和输出长度不变，比较短/长输入、单请求/多请求；分别记录首token和完整响应，不把两者混成“速度”。

## 5. 自动科研的最小闭环

收藏 X08 的启发是尽早用小实验检验猜想。一个可操作流程是：提出明确假设 → 写出可能推翻它的结果 → 建最小实验 → 保存输入和结果 → 再扩大规模。

例如有人猜“损失函数数值降低一半，模型一定训练得更好”。先构造反例：给损失加常数，数值改变但对参数的梯度不变。若L'=L+100，则对参数θ求导有∂L'/∂θ=∂L/∂θ。单凭损失绝对数值不能跨不同定义比较模型质量。

如果把L乘以0.5，梯度会缩放，但它与优化器、学习率、归一化等共同作用，也不能只看数值下结论。实验应比较同一任务的实际评估结果。

科研Agent可协助写代码、跑实验和整理结果；独立验证仍要检查代码是否实现了假设、对照是否公平、指标是否与结论匹配。让生成实验的同一个过程挑选最好结果再写结论，容易把失败记录丢掉。

## 6. 如何研究“新记忆机制”

X10涉及模型内部表示、近邻检索等方向。做最小实验时，先选具体任务，例如罕见名称恢复。保持模型、训练数据、测试集一致，比较无检索、普通检索、新记忆策略。记录检索数据库里是否已经包含测试答案，以及检索带来的额外时间和存储。

若新方法多看了额外数据，收益可能来自数据而非机制。可以再加“相同数据、不同检索方式”的对照，把这两种解释分开。

## 7. 练习与答案

**题：用LoRA训练教师生成的指令回答，这个实验应叫哪一种？** 参数更新方式是LoRA，训练目标可为SFT，数据来自教师且目标是迁移能力时可描述为蒸馏流程；应同时说明三个维度。

**题：模型A训练损失0.5，B是1.0，A一定更好吗？** 需要确认损失定义、数据和归一化一致；最终还需在同一独立评估集比较任务效果。

**可以开始的作品：** 一个实验记录表，包含假设、数据版本、模型版本、改动、对照、指标、结果和失败案例。先复现一个小分类任务，再引入教师数据，比直接启动全自动科研系统更容易看懂每一步。
