# 商业与组织案例：把故事变成可分析过程

范围：X01、X04、X11、X13、X21、X24、X25。当前大部分只有标题和简短正文，因此本专题提供阅读框架，尚未形成对这些案例成败的结论。

| 要提取的信息 | 对应问题 |
| --- | --- |
| 客户与付费物 | 谁付钱、买什么、为什么复购？ |
| 完整流程 | 获客、交付、售后各由谁完成？ |
| Agent职责 | 具体输入、动作和输出是什么？ |
| 人工投入 | 谁制定策略、处理异常、验收结果？ |
| 收益口径 | 是营收、毛利、净利还是累计流水？ |
| 成本与约束 | 广告、库存、物流、模型、软件和工时如何计入？ |
| 证据 | 是否给出后台、订单、对照组或可重做案例？ |
